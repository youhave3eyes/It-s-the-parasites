# Videos

Put your own video files here (for example `rat.mp4`, `cricket.mp4`, `ant.mp4`, `brain.mp4`, `pork.mp4`, `beef.mp4`, `fish.mp4`, `game.mp4`).

Then in `index.html`, find `HOW TO ADD VIDEOS` and set `video:'videos/rat.mp4'` on the matching entry.

- Use .mp4 (H.264), 720p is plenty.
- Keep each file under 100 MB. Under 25 MB loads fastest on phones.
- Only upload footage you shot yourself or have the rights to use.
